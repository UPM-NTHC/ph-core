Resource Profile: PH Core Location

Official URL: https://fhir.doh.gov.ph/phcore/StructureDefinition/ph-core-location Version: 0.2.1
Draft as of 2026-10-26 Maturity Level: 0 Computable Name: PHCoreLocation

This profile localizes the FHIR R4 Location resource to the Philippine context.

Usages:

  • Refer to this Profile: PH Core Encounter, PH Core HealthcareService, PH Core Immunization, PH Core Location... , PH Core Medication Dispense, PH Core PractitionerRole, PH Core Procedure, PH Core Provenance, PH Core ServiceRequest and PH Core Task
  • Examples for this Profile: Philippine General Hospital
  • CapabilityStatements using this Profile: CapabilityStatement[https://fhir.doh.gov.ph/phcore/CapabilityStatement/PHCoreServerCapabilityStatement|0.2.1]
